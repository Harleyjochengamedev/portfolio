## 🚀 Sobre o Projeto

Portfólio profissional desenvolvido para apresentar minhas habilidades, experiência e projetos como Desenvolvedor Full Stack. O site possui design moderno com efeitos de glassmorphism, totalmente responsivo e otimizado para performance.

**Live Demo:** [https://harleysteffen.dev](https://harleysteffen.dev) *(ou seu link do GitHub Pages)*

## ✨ Funcionalidades

- ✅ Design moderno com Glassmorphism
- ✅ Totalmente responsivo (Mobile First)
- ✅ Navegação suave entre seções
- ✅ Formulário de contato funcional
- ✅ Integração com WhatsApp
- ✅ Links para redes sociais
- ✅ Barra de habilidades interativa
- ✅ Efeito de digitação no título
- ✅ Animações suaves
- ✅ Barra de rolagem personalizada

## 🛠️ Tecnologias Utilizadas

### Frontend
- **HTML5** - Estrutura semântica
- **CSS3** - Estilização avançada (Grid, Flexbox, Variáveis CSS, Animations)
- **JavaScript (Vanilla)** - Interatividade e funcionalidades
- **Font Awesome** - Ícones
- **Google Fonts** - Tipografia (Poppins, Roboto Mono)

### Design
- Glassmorphism (efeito vidro)
- Gradientes modernos
- Design responsivo
- Paleta de cores azul/ciano
- Micro-interações

## 🎯 Seções do Portfólio

1. **Home** - Apresentação com efeito de digitação
2. **Sobre** - Informações pessoais e habilidades técnicas
3. **Formação** - Histórico acadêmico
4. **Experiência** - Histórico profissional (Estágio IPOM)
5. **Competências** - Habilidades técnicas e áreas de conhecimento
6. **Cursos** - Certificações e cursos realizados
7. **Contato** - Formulário e informações de contato

## 📱 Responsividade

O portfólio é totalmente responsivo e se adapta a:

- 📱 Mobile (320px - 768px)
- 📟 Tablet (768px - 1024px)
- 💻 Desktop (1024px+)
